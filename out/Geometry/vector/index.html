座標與向量

學習在程式競賽中最廣泛做使用的計算幾何框架。

計算幾何導論

講到幾何題，初學者可能會想到國高中時學過的與圖形有關的題目，但在資訊競賽中，不論是題目還是寫程式，要人性的處理圖形勢必得找一些乾淨的表示法，而最常見的作法就是利用「解析幾何」的方式，將所有幾何元件都以座標和向量表示。

回想一下國中數學，如果我們想要表示一條直線，可能會表示成如 $y=ax+b$ 的方程式，要求兩條直線的交點，就是解兩個方程式的聯立方程式……可是這樣的方程式並不能表示一條鉛直線，所以我們可能會想用 $ax+by+c=0$ 之類的方式表示直線，要解聯立方程式好像就稍微麻煩了一點。要是一開始直線就是以這樣的形式給出，那還不算太麻煩，但要是題目給的是「有一條經過某兩個點的直線」呢？還要把座標代進去再把 $a,b,c$ 算出來，這樣不煩嗎？

於是，這就凸顯了向量的重要性！在計算幾何之中，這些幾何元件之間的運算經常會使用向量來處理，在資訊競賽中，使用向量表示幾何元件便成為了主流的做法。

以下就來簡介一下這個所謂的向量究竟是什麼。

向量

在幾何的世界中，向量（vector）是一個表示特定的長度和方向的箭頭，可以拿來表示很多東西，像是位移（往什麼方向移動多少距離）、物理的力（往哪個方向施多少力）等等。

任何維度的世界裡都有向量，也就是說，有二維向量、也有三維向量、一維向量……，然後一個 $d$ 維向量可以用 $d$ 個數字來表示，第 $i$ 個數字表示要往第 $i$ 個維度的正向走多少距離（如果是負數，就是往負向走），而這個向量可以被看成是一個從起點指向終點的箭頭，舉例來說：

這是一個二維向量，它表示向著 $x$ 軸正向走 $2$，並向著 $y$ 軸正向走 $3$，所以如果從原點開始走，會走到點 $(2,3)$。

向量有幾種表示方式，有把數字放在矩陣裡，寫成
$\begin{bmatrix}
v_1\\
v_2\\
\vdots
\end{bmatrix}$
這種形式的（通常是直的），也有放在 tuple 裡，寫成 $(v_1, v_2, \dots)$ 的，要使用什麼方式表示，通常跟領域有關，打程式競賽的人通常都喜歡寫成 tuple 的形式。於是，一個二維向量就會表示成形如 $(x,y)$ 的形式，表示往 $x$ 軸正向移動 $x$ 單位、$y$ 軸正向移動 $y$ 單位，就跟表示一個平面上的點一樣簡單！事實上，這個向量就是從原點移動到 $(x,y)$ 這個點的位移量。

在程式競賽裡，計算幾何的題目大多數都處於二維的世界，頂多只有 ICPC 中少數的題目會出現三維幾何，因此接下來我們都以二維向量來介紹基礎的向量運算。

剛才說到向量表示特定的方向和長度，向量 $\vec{v} = (x,y)$ 的長度是多少呢？國中學的畢氏定理已經告訴我們了：
$$\lvert \vec{v} \rvert = \sqrt{x^2 + y^2}$$
為了避免搞混，講義中會像這樣在向量的名字上面加上那個小箭頭，來代表這個東西是個向量，這個表示方法在其他地方可能會有些不同。「向量的絕對值」也就是 $\lvert \vec{v} \rvert$ 這樣的符號，就代表這個向量的長度。

長度為 $0$ 的向量稱為「零向量」，剛才我們說到一條向量表示「特定的長度和方向」，但是沒有長度的向量的方向究竟是什呢？畢竟我們也不能給它規定一個方向，說它沒有方向又怪怪的，所以我們就當作它「所有方向都是」。為了方便，除非特別註明，接下來討論的向量都不包含零向量。不過在大多數時候，仔細想一想會發現，將零向量當作「所有方向都是」的話，很多敘述都會是正確的！不過也有的時候，零向量的存在會導致怪怪的事情發生，在有可能出現零向量的時候要特別小心。

接下來，我們定義一些基本符號：

  • $\overrightarrow{AB}$，也就是 $\overrightarrow{B}-\overrightarrow{A}$，$A$、$B$ 是點，表示由 $A$ 指向 $B$ 的向量。（注意向量沒有特定的起終點，只能規定它的方向和長度）
  • $\overrightarrow{A}$，$A$ 是點，等同於 $\overrightarrow{OA}$，$O$ 是原點。

基本運算

加減

兩個向量可以相加得到新的向量，就把 $x,y$ 分別相加就好：
$$
(x_1,y_1)+(x_2,y_2)=(x_1+y_1,x_2+y_2)
$$
想像上來說就是把兩個向量頭尾相接（有交換律，順序是沒差的！），得到一個新的向量。

例如，$(2,3)+(3,1)=(5,4)$：

至於減法也是同理，就是把 $x,y$ 分別相減（減法當然沒有交換律）。

  • 也可以想成是一個向量加上另一個向量的反向，$\vec{v}_1-\vec{v}_2=\vec{v}_1+(-\vec{v}_2)$，一個向量的反向就是把它的 $x,y$ 都乘上 $-1$。
  • 或是想成是兩個點相減，$\overrightarrow{A}-\overrightarrow{B}=\overrightarrow{BA}$。

例如， $(2, 3)-(3, 1)=(-1, 2)$：

純量乘法

沒有方向的量稱為純量，像是 $1$、$\frac{1}{2}$、$\pi$ 這些數字都是純量。向量可以乘上一個純量，得到一個新的向量，也就是將這個向量的長度乘上某一個數字，得到一個新的向量，這個動作非常簡單，就把 $x,y$ 都乘上這個純量就好：
$$i \cdot (x, y)=(i \cdot x, i \cdot y)$$

例如，$2 \cdot (2,3)=(4,6)$：

內積 (dot product)

接下來要講的運算就是向量特有的了。兩個向量 $\vec{u} = (x_1,y_1)$ 和 $\vec{v} = (x_2,y_2)$ 的內積記作 $\vec{u} \cdot \vec{v}$，它的結果是一個純量，數值是
$$
\vec{u} \cdot \vec{v} = x_1 y_1 + x_2 y_2
$$
就是 $x$ 相乘、$y$ 相乘，然後相加。因為它的符號是一個點，另一種翻譯是「點積」，英文叫作 dot product。

至於這個神奇的運算是什麼意思呢？雖然它的式子很簡單，但它可厲害了，這個數值剛好就是「$\vec{u}$ 投影到 $\vec{v}$ 上的長度，再乘上 $\vec{v}$ 的長度」，例如

黑色的那段就是 $\vec{u}$ 投影到 $\vec{v}$ 上面的長度。這個運算很明顯地有交換律，所以它也是 $\vec{v}$ 投影到 $\vec{u}$ 上的長度，再乘上 $\vec{u}$ 的長度。當它們的夾角是 $\theta$ 時，投影長度是 $\lvert \vec{u} \rvert \cos \theta$，再乘上 $\lvert \vec{v} \rvert$ 就是內積了，所以內積也可以寫成 $\vec{u} \cdot \vec{v} = \lvert u \vert \lvert v \rvert \cos \theta$。（這個 $\theta$ 選裡面的角和外面的角是沒差的，算出來都一樣。）

如果 $\vec{u}$ 對 $\vec{v}$ 的投影在 $\vec{v}$ 的另一邊的話呢？這個時候內積的數值會是負的，$\cos \theta$ 也會是負的。所以，內積的一個常用用途是判斷「兩個向量是同方向、垂直還是反方向」，這裡的同方向不是指指向完全一樣的方向，而是夾角是不是小於 $90^\circ$。如果兩個向量垂直，內積就會是 $0$。

這張圖是各種夾角時 $\vec{u} \cdot \vec{v}$ 的範圍：

1 / 16

這也告訴了我們 $-\lvert \vec{u} \rvert \lvert \vec{v} \rvert \leq \vec{u} \cdot \vec{v} \leq \lvert \vec{u} \rvert \lvert \vec{v} \rvert$，這就是柯西不等式（Cauchy-Schwarz inequality）！

外積 (cross prodoct)

這也是向量特有的運算，兩個向量 $\vec{u} = (x_1,y_1)$ 和 $\vec{v} = (x_2,y_2)$ 的外積記作 $\vec{u} \times \vec{v}$，它的結果也是一個純量，數值是
$$
\vec{u} \times \vec{v} = x_1 y_2 - x_2 y_1
$$
這看起來比內積奇怪多了，筆者記住這個式子的方法是記「外乘外減內乘內」，它其實就是行列式 $\begin{vmatrix}x_1 & y_1 \\ x_2 & y_2\end{vmatrix}$。

那它的意義是什麼呢？外積也很厲害，這個數值是 $\vec{u}$ 和 $\vec{v}$ 兩個向量當其中兩個邊的平行四邊形面積！

這個平行四邊形是底 $\lvert \vec{u} \rvert$ 配上高 $\lvert \vec{v} \rvert \sin \theta$，或是底 $\lvert \vec{v} \rvert$ 配上高 $\lvert \vec{u} \rvert \sin \theta$，所以外積的數值也就是 $\lvert \vec{u} \rvert \lvert \vec{v} \rvert \sin \theta$。注意這裡的 $\theta$ 可不是選哪個角都行，而是必須要「從 $\vec{u}$ 逆時針轉到 $\vec{v}$」的那個角，否則答案會差一個正負號！也就是說，外積沒有交換律，把兩個向量交換之後外積會乘上 $-1$。這個正負號代表的是「從 $\vec{u}$ 轉到 $\vec{v}$ 是往逆時針轉比較近，還是往順時針轉比較近」，往逆時針轉比較近的話，外積就是正的、往順時針轉比較近就是負的，一樣近（也就是兩個向量完全同向或完全反向）就是 $0$。

下圖是在各種夾角時外積的範圍，這次我們整圈都要畫出來了：

如果讀者有在其他地方學過外積，有可能會發現這裡我們說的外積不太一樣。在高中數學課本裡面，外積是三維向量的運算，結果也是一個三維向量，那個向量垂直於運算的兩個向量、長度就是我們剛剛說的平行四邊形面積，這個垂直向量的方向對應到我們剛才算出來的正負號。因為外積用在二維也很方便，所以我們把三維外積的定義「借用」過來。

實作

在實作時，可以自己寫一個 struct 或 class，或使用 STL 的 std::pair<T, T> 儲存，優點是 std::pair 內建字典序排序，在要用掃描線的時候（例如凸包）很方便；也可以用 STL 的 complex<T>，也就是複數，雖然沒有內建排序，但在做旋轉、伸縮等等操作時，用複數運算可以很輕鬆地做到。

為了在幾何上做運算，活用向量的四則運算等操作是非常重要的，其中內外積又更格外重要（後面就會見識到），因此在準備寫計算幾何的題目前，會先把基本的向量操作寫成 default code 以利解題時使用。

下面是一份使用 std::pair 的範例程式碼：

cpp
#define X first
#define Y second
typedef pair<long long, long long> pll;

pll operator+(pll a, pll b) // 加法
{ return pll(a.X + b.X, a.Y + b.Y); }
pll operator-(pll a, pll b) // 減法
{ return pll(a.X - b.X, a.Y - b.Y); }
pll operator*(pll a, long long b) // 乘法
{ return pll(a.X * b, a.Y * b); }
pll operator/(pll a, long long b) // 整數除法
{ return pll(a.X / b, a.Y / b); }

long long dot(pll a, pll b) // 內積
{ return a.X * b.X + a.Y * b.Y; }
long long cross(pll a, pll b) // 外積
{ return a.X * b.Y - a.Y * b.X; }
long long abs2(pll a) // 向量長度平方
{ return dot(a, a); }
double abs(pll a) // 向量長度
{ return sqrt(dot(a, a)); }

讀者可以注意到裡面還實作了除法運算子，但有特別強調是「整數除法」。如果遇到除完不是整數的情況，就會需要面對浮點數、並把點的型態全部從 long long 改成 double，屆時會有非常多可怕的事情需要做考量，這部分我們會在下一篇文章再做詳細一點的解釋。

往後提供的範例程式碼都會以這份 default code 為基礎實作，若讀者有自己實作的風格但想參考皆可自行修改。

小測驗

動動腦

我們在這篇文章中學到了內積與外積。在計算幾何上，有許多基礎操作其實會是內積與外積的實際應用。請針對以下幾種小問題，回答出該小問題是內積、外積的直接應用。

  • 判斷兩向量是否垂直
  • 判斷兩向量是否平行
  • 計算兩向量所夾的平行四邊形面積
  • 計算兩向量所夾的三角形面積
  • 判斷兩向量是同向還是反向
  • 判斷向量 $\overrightarrow{u}$ 轉到向量 $\overrightarrow{v}$ 是順時針還是逆時針
解答
  • 內積（判斷兩向量之內積是否為 $0$）
  • 外積（判斷兩向量之外積是否為 $0$）
  • 外積（直接取得兩向量外積之絕對值）
  • 外積（直接取得兩向量外積之絕對值除以二）
  • 內積（判斷兩向量內積之正負號，正號代表同向、負號代表反向，$0$ 則代表垂直）
  • 外積（判斷兩向量外積之正負號，正號代表逆時針、負號代表順直針，$0$ 則代表平行）

習題

向左轉向右轉

Source:Sprout OJ 355

當你學會用座標表示點後，你便開始記錄你時時刻刻在平面上的位置。由於你移動的時候都是走直線的，因此，你所記錄的座標兩兩間都是以直線到達，比如說上一個記錄的座標點爲 $(0,0)$，這次所記錄的座標點爲 $(1,1)$，你便是從座標 $(0,0)$ 走 $x=y$ 這條直線到達 $(1,1)$。

回家之後，你發現今天一共記錄了 $N$ 個座標點，你很好奇，究竟今天你左轉了幾次、右轉了幾次、回頭了幾次？

假設你現在行進的方向是朝着 $x$ 軸正方向前進，如果接下來往 $x$ 軸負方向前進便定義爲回頭，如果接下來往上半平面前進便定義爲左轉，如果接下來往下半平面前進便定義爲右轉。

條件限制
  • $1 \le N \leq 10^ 6$
  • $0 \le |x_i|,|y_i| \le 10^ 9$
  • 保證所有相鄰的兩個座標點皆不相同
